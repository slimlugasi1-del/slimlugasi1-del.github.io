# ForgeHub

top shelf uncensored distilled and obliterated AI models 

## Run locally

Open `index.html` directly, or serve the folder with:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Included

- Live public model metadata from the Hugging Face Hub API
- Search, model filters, model detail dialogs, and model-card links
- Agent workflow cards
- Training/customization workspace UI
- Local fallback models when the API is unavailable

The training and agent controls are currently front-end interactions. Connect a backend, authentication, GPU provider, and database before using them for real jobs.
